# @lynage/ai-sdk

**Vercel AI SDK adapter for [Lynage](https://github.com/qiao-coding/lynage-memory)** — implements Lynage's model interface on top of any AI SDK language model (OpenAI, DeepSeek, Anthropic, …) for archiving summaries, search rerank, and directory navigation.

```bash
pnpm add @lynage/ai-sdk
```

Full usage and API: [github.com/qiao-coding/lynage-memory](https://github.com/qiao-coding/lynage-memory)
