# @lynage/core

**The core engine of [Lynage](https://github.com/qiao-coding/lynage-memory)** — a long-term story memory system for AI agents. Handles memory, layered search (FTS → embedding → LLM rerank), archiving, generational compaction, and source verification. Storage-agnostic.

```bash
pnpm add @lynage/core
```

Full usage and API: [github.com/qiao-coding/lynage-memory](https://github.com/qiao-coding/lynage-memory)
