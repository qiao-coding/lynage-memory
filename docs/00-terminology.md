# 术语表

> Lynage Memory 所有概念的唯一标准命名。其他文档均以此表为准。

---

## 核心概念层级

```
工作区 (父类上下文)
  └── 阶段 (子类上下文，可嵌套)
        └── 窗口 (子类上下文，一段冻结的对话)
              └── 消息 (原文)
```

---

## 存储层（自底向上）

| 术语 | English | 一句话定义 | 别再叫 |
|------|---------|-----------|--------|
| **消息** | Message | 一条对话记录（user/assistant/tool），追加写入，永不修改 | msg、消息记录、聊天记录 |
| **窗口** | Context Chunk | 一段被冻结的连续对话。超出 Token 阈值后，旧消息打包成一个窗口，附 AI 生成的摘要标签 | 档案袋、Chunk、上下文块、冻结窗口、子上下文 |
| **阶段** | Directory | 一组窗口的容器。记录了这段时间项目推进了什么、形成了什么结论。阶段可以嵌套 | 目录、目录柜、子上下文分组、工作区上下文 |
| **工作区** | Root Directory | 一个项目/任务。工作区下包含若干阶段，阶段下包含若干窗口。最顶层的工作区=G0 | 项目根目录、父类上下文 |

## 记忆层

| 术语 | English | 一句话定义 | 别再叫 |
|------|---------|-----------|--------|
| **工作记忆** | Working Memory | 当前任务的状态便签——正在做什么、已确定什么、还没解决什么。随对话实时更新 | WM、便签纸、项目状态 |
| **用户画像** | User Memory | 跨任务的稳定信息——用户偏好、长期约束、背景。很少变化 | UM、用户记忆、用户偏好 |

## 操作

| 术语 | English | 一句话定义 | 别再叫 |
|------|---------|-----------|--------|
| **归档** | Archive | 当前对话超出 Token 阈值 → 找到自然边界 → 旧对话冻结成窗口的过程 | 存档、打包、装袋 |
| **升代** | Generational Compaction | 一个阶段下的窗口数达到上限(20) → 创建上层阶段来概括它们。窗口套阶段，阶段套阶段 | 代际压缩、窗口套窗口、分组 |
| **编译** | Compile | 从数据库筛选出当前场景需要的内容，格式化为 LLM 能看的文本 | 上下文编译、拼装 |
| **写回** | Commit | LLM 提出增量记忆操作(append/remove) → Zod 校验 → 写入工作记忆或用户画像 | 记忆操作、memory action |

## 检索

| 术语 | English | 一句话定义 | 别再叫 |
|------|---------|-----------|--------|
| **搜索** | Search | 在所有窗口的摘要中找匹配 → 打开原文验证 → 返回结果。混合了 FTS5 关键词和阶段摘要匹配 | 检索、查找、历史搜索 |
| **模糊搜索** | Persistent Fuzzy Search | 问题太模糊时，创建搜索任务 → 分批检查窗口 → 保存进度 → 跨轮次继续 | 持久化搜索、分批搜索 |
| **并行搜索** | Parallel Search | 主进程创建项目快照 → 多个 Worker 并发读不同窗口 → 汇总验证 | 共享上下文并行搜索 |
| **原文验证** | Source Verification | 搜索返回候选窗口后，打开里面的原始消息，确认"真的匹配"。过滤掉摘要不准确的误报 | 校验、核实 |

## 结构关系

```
工作区: React 组件库开发
  │
  ├── 阶段: 前期开发 (G1)
  │     │  摘要: "完成技术选型、基础组件和样式迁移"
  │     │
  │     └── 窗口 #1: 技术选型讨论 (第 1~42 轮)
  │     │    摘要: "确定 CSS Modules + TS + Vite"
  │     │    消息: msg-1 ~ msg-84
  │     │
  │     └── 窗口 #2: 初期组件开发 (第 43~82 轮)
  │           ...
  │
  ├── 阶段: 架构重构 (G1)
  │     └── ...
  │
  └── 当前对话 (尚未冻结)
        消息: msg-381 ~ msg-400

工作记忆:
  currentTask    组件库 v2.0 重构
  confirmed      monorepo 架构
  unresolved     状态管理选什么？

用户画像:
  preferences    回答简洁直接
  constraints    不用向量数据库
```
