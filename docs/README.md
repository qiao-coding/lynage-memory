## 术语速查

| 术语 | 一句话 |
|------|--------|
| **消息** | 一条对话记录，追加写入，永不修改 |
| **窗口** | 一段被冻结的连续对话（带摘要标签） |
| **阶段** | 一组窗口的容器，可嵌套 |
| **工作区** | 一个项目/任务，最顶层的阶段 |
| **升代** | 阶段满 → 创建上层阶段概括（G0→G1→G2） |
| **工作记忆** | 当前任务状态便签 |
| **用户画像** | 长期不变的偏好和约束 |
| **归档** | 旧对话 → 冻结成窗口 |
| **编译** | 筛选数据库内容 → LLM 可读文本 |
| **写回** | LLM 提出增量操作 → 校验 → 写入记忆 |
| **搜索** | 在所有窗口中匹配 → 原文验证 → 返回 |
| **模糊搜索** | 分批检查窗口 → 保存进度 → 跨轮次继续 |
| **并行搜索** | 多个 Worker 并发读不同窗口 |
| **原文验证** | 打开窗口原文，确认搜索匹配真实 |
