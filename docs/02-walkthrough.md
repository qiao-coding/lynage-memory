# 全程推演：一次对话的完整生命周期

> 场景：用户正在开发一个 React 组件库。假设归档阈值 = 2000 tokens（便于演示）。
>
> 核心概念：每个 **Context Chunk = 一个冻结的上下文窗口**（一段连续对话的快照）。

---

## 第 1 轮 · 项目启动

```
用户: "我要做一个 React 组件库，帮我设计技术方案"
AI:   "建议用 TypeScript + Vite 构建，组件用函数式写法..."
```

**此时各层状态：**

```
当前活跃窗口 (Recent Context):        Working Memory:
  ┌──────────────────────┐            (空)
  │ 第 1 轮对话            │
  │ (1 个上下文窗口)       │
  └──────────────────────┘

历史窗口 (Chunks):        目录:
  (无)                      (无)
```

## 第 160 轮 · 从历史窗口找回上下文

团队壮大，重新讨论 monorepo 方案。Agent 需要找回之前的讨论。

```
用户:  "团队 5 个人了，之前那个 monorepo 方案现在可以做了"
AI:    "让我查一下之前是怎么讨论的..."

lynageSearch("monorepo")
  → 在历史窗口中搜索 "monorepo"
  → 找到 窗口 #1 (第 1~42 轮) 中有相关讨论
  → 打开 窗口 #1，阅读当时的原文
  → 发现: 第 25 轮决定不做 monorepo（"过早优化"）

AI:    "找到了。之前在第 25 轮我们决定不做 monorepo，
        理由是只有 3 个包，拆 monorepo 是过早优化。
        现在有 5 个包了，条件已满足。"
```

**搜索过程（用户视角）：**

```
lynageSearch("monorepo")
    │
    ├─ ① 在所有历史窗口的摘要中搜索 "monorepo"
    │      → 窗口 #1 的摘要匹配（"讨论过 monorepo 但放弃"）
    │
    ├─ ② 打开窗口 #1，验证原文
    │      → 确认原文确实在讨论 monorepo
    │      → 置信度 90%
    │
    └─ ③ 把窗口 #1 的内容加载到当前上下文
           → LLM 现在能看到当时的完整讨论
```

## 关键理解

```
一个 Context Chunk  =  一个冻结的上下文窗口
                     =  一段连续对话的快照
                     =  "第 1~42 轮: 技术选型讨论"

代际目录            =  窗口套窗口
                     =  G2("整个项目") → G1("前期开发") → G0 → 窗口

搜索历史            =  在所有窗口的摘要中搜索
                     → 找到相关窗口
                     → 打开那个窗口，恢复当时的上下文

当前活跃窗口         =  还没冻结的最近对话
                     → 超出阈值后自动冻结成一个新窗口
```

**用户看到的是上下文窗口。系统内部用 msg ID 精确追踪。**
